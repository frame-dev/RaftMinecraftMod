Raft Ocean 0.13.8 is a **preview pre-release** for Minecraft Java 26.3. It includes the development updates since 0.13.0 and keeps the story open-ended.

## Requirements and installation

- Minecraft Java **26.3**, NeoForge **26.3.0.48-beta**, 64-bit **Java 25**.
- Install only **raft_ocean-0.13.8.jar** in `mods`. Remove older Raft Ocean JARs.
- Every multiplayer client and server must use **0.13.8** (movement handshake13.8).
- Optional JEI: **31.9.0.58** for Minecraft26.3/NeoForge; install separately.
- Sources JAR and addon SDK are for developers. Minecraft, NeoForge, Java and JEI are not bundled.
- Back up existing worlds/configs before updating. Create an **Ocean World** for raft survival; larger island generation appears only in new chunks.

## Added since 0.13.0

- Battery-powered **Raft Juicer**: four food portions, Blend/Pause/Serve controls, saved batches, separate glass serving, three original drinks, reusable glasses, custom models, recipe data and optional JEI links.
- **Salvage Compactor**: mixed surplus materials become tradeable bales, with five new outpost purchases and saved-stock migration.
- Deliberate single-batch cooking, saved queue/progress and an automatic-processing compatibility option.
- Wind-limited shared sail drive, engine foundation-load bands and clearer navigation feedback. User-selected engine/sail/paddle base speeds remain1.5/1.0/1.8m/s.
- Mounted survey receiver, three-antenna setup, battery power, radar and a persistent expedition notebook with28field notes.
- Seven original story schematic discoveries, eight gated advanced projects, harder material-study batches and larger staged story islands. Earlier learned research is retained; the story remains open-ended.
- Configurable ten-minute shark/five-minute bird delays and Peaceful protections retained. Addon API3 retained.

## Known limits

- Live GUI/JEI appearance, real co-op latency, older user saves, large-raft performance and full survival balance still need playtesting. Earlier reported movement/collision issues require user confirmation; rotating collision uses conservative axis-aligned approximations.
- Juicer uses native portable batteries. Wired/foreign power, bonus-water reserves and invalid-recipe leftovers are absent. Glasses are intentionally reusable; dismantling spills an unserved drink.
- Coins, trading reputation/special fish and a recycling JEI category remain future work. Cooking retains existing two-food/water/bowl recipes, without four-food cooking pads or post-cooking bowl collection.
- Foreign machines need dedicated moving-raft adapters. No universal technology-mod compatibility is claimed. NeoForge itself is beta.
- New island sizes affect newly generated chunks. The seven-destination story intentionally remains unresolved.

All models, lore and sounds are original. No Raft game assets or text are bundled. See the included CHANGELOG.md, KNOWN_ISSUES.md and RELEASE_VERIFICATION.md for details.
